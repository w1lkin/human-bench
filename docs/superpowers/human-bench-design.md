# 人类基准测试 — 设计文档

## 产品定位

受 Human Benchmark 启发的认知能力测试合集。用户在手机上完成各项测试，查看自己的单项得分，对比百分位排名。

## 交互流程

```
主菜单（7 项测试卡片）→ 点击某项 → 测试说明页 → 开始测试 → 测试过程 → 结果展示 → 返回主菜单
```

主菜单 → 点击测试 → 展示规则说明（一句话 + "开始测试"按钮）→ 测试 → 完成后自动展示结果（本次得分 + 历史最佳 + 返回按钮）。

## 视觉主题

深色科技感风格，灵感来自 Human Benchmark 原版：

- 背景：`#1a1a2e`（深蓝黑）
- 卡片/面板：`#16213e`（深蓝）
- 主色调：`#0f3460`（中蓝）+ `#e94560`（珊瑚红强调色）
- 文字：`#eaeaea`（浅灰白）用于主文字，`#a0a0b0` 用于次要文字
- 成功色：`#4ecca3`（青绿），用于正反馈
- 警告色：`#ffd369`（金黄），用于提示

- 字体：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- Card 圆角 14px，轻微阴影
- 按钮采用主色调渐变

## 各子测试设计

### 1. 反应速度（Reaction Time）

- 流程：红色屏幕（等待）→ 随机延迟（1-5s）→ 绿色屏幕（点击）→ 显示反应时间 → 重复 5 次 → 展示平均反应时间
- 过早点击（红色时点击）→ 显示"太快了！等一下再试" → 重新开始本轮
- 5 次取平均，单位为毫秒，保留 1 位小数

### 2. 数字记忆（Number Memory）

- 流程：依次展示递增位数的数字（从 1 位开始），每位数展示后消失 → 用户在输入框中复述 → 正确则位数+1 → 错误则结束
- 每位数字展示 2 秒（位数越多展示时间越长：`max(2, digits * 0.5)` 秒）
- 记录用户成功记住的最大位数

### 3. 词汇记忆（Verbal Memory）

- 流程：逐个展示词汇（"新词"或"已见词"），用户判断是否见过 → 对则继续 → 错则结束
- 词库：50+ 个中文双字词，首次出现为"新词"，后续出现为"已见词"
- 新词/已见词随机混合，约 30% 为新词
- 记录判对的总数

### 4. 视觉记忆（Visual Memory）

- 流程：3×3 至 9×9 网格中随机亮起若干格子（亮 2 秒）→ 格子变暗 → 用户点击刚才亮起的格子 → 全对则格子数+1 → 有错则结束
- 从 3 个亮格开始，每轮增加 1 个
- 记录成功记住的最大格子数

### 5. 序列记忆（Sequence Memory）

- 流程：3×3 网格中随机方块依次短暂亮起 → 用户按顺序点击 → 正确则序列+1 → 错误则结束
- 初始序列长度为 1，每轮+1
- 每格亮起 0.5 秒
- 记录最大正确序列长度

### 6. 打字速度（Typing Speed）

- 流程：屏幕上方展示一段英文文本 → 用户在下方输入框输入 → 60 秒计时结束或输入完毕 → 显示 WPM 和准确率
- 预置若干段英文短句（约 200 词），随机选取
- 实时标记已输入字符的正确/错误状态
- WPM = (正确输入字符数 / 5) / 分钟

### 7. 瞄准训练（Aim Trainer）

- 流程：屏幕上随机位置出现 30 个圆形目标 → 用户尽快点击 → 记录每个目标从出现到点击的时间
- 目标大小约 40px，随机分布
- 每点击一个目标，下一个立即出现在新位置
- 完成 30 个后显示平均反应时间和命中率

## 百分位参考数据（内置对照表）

每个测试完成后显示一个参考百分位（基于公开的 Human Benchmark 数据）：
- 反应速度：< 200ms → 99%，200-250 → 90%，250-300 → 70%，300-350 → 40%，> 350 → 20%
- 其他测试逐步完善
