# 人类基准测试（Human Bench）

纯前端单机认知测试合集：7 项小游戏测你的反应速度、记忆力、打字速度与瞄准能力，灵感来自 Human Benchmark。

## 特性

- **纯静态**：单文件 `index.html`（内联 CSS/JS），零依赖、无构建步骤。
- **测试逻辑本地运行**：各子测试计算全部在浏览器完成，仅战绩上报需联网。
- **数据云端**：各测试成绩通过 `GamePlatform` SDK 上报云端（需登录后游玩），本地不再保存任何数据。
- **即开即玩**：浏览器打开即可运行；移动端已适配触屏与微信 webview。

## 包含的测试

| 测试 | 玩法 | 衡量指标 |
|---|---|---|
| ⚡ 反应速度 | 屏幕变绿时尽快点击 | 平均反应时间（ms，越小越好） |
| 🔢 数字记忆 | 记住并复述逐渐变长的数字串 | 最大位数 |
| 📝 词汇记忆 | 判断词汇是否出现过 | 正确次数 |
| 👁️ 视觉记忆 | 记住并复现亮起格子的位置 | 最大格子数 |
| 🧠 序列记忆 | 记住并复现方块亮起顺序 | 最大序列长度 |
| ⌨️ 打字速度 | 限时内尽量快准地输入英文 | WPM |
| 🎯 瞄准训练 | 尽快点击随机出现的目标 | 平均反应时间（ms，越小越好） |

每项测试结束展示成绩、历史最佳与趣味百分位（如「超越 90% 的人」），并可一键生成分享卡片。

## 本地运行

```sh
cd human-bench
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 分享卡片的二维码依赖 `api.qrserver.com`，必须经 `http(s)` 来源加载，请用上面的本地服务器方式，不要直接 `file://` 打开。
